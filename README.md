# 🫁 Lung Cancer Detection using Deep Learning

## 📌 Project Overview

This project is a Deep Learning-based web application that detects lung cancer from lung histopathology (microscopic tissue) images. The system classifies uploaded images into one of the supported categories and displays the prediction with confidence.

## 🎯 Objective

The objective of this project is to classify lung histopathology images using a trained Deep Learning model and assist in identifying different lung tissue types.

---

## 🧠 Supported Image Types

This system accepts only **Lung Histopathology (Microscopic Tissue) Images**.

### Supported Classes

- Adenocarcinoma
- Normal Lung
- Squamous Cell Carcinoma

> ⚠ **Warning:**  
> Please upload only supported lung histopathology images. Images outside the supported tissue types or unsupported classes may not be classified accurately.
